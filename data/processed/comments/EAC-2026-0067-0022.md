# EAC-2026-0067-0022 — Julie Adams

**Date:** 2026-05-20
**Docket:** EAC-2026-0067
**Source:** [Regulations.gov](https://www.regulations.gov/comment/EAC-2026-0067-0022)

---

All audits of elections should be done INDEPENDENTLY! Audits done by election employees or election officials are not real audits. The audits should not be done by election officials, vendors of elections or state election officials. It should be done by a credible audit firm or state auditors.
